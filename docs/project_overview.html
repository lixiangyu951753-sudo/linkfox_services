🔗 LinkFox AI 后台

智能商品套图生成系统 · 浅显版说明

💬 一句话解释

这是一个中间人服务。用户提交"帮我给这张商品图做套图"的请求，这个服务把它转发给一个叫 LinkFox 的 AI 作图平台，等 AI 画完之后把结果存下来，通知用户来拿。

步骤拆解

步骤谁干的做了什么
1. 接收FastAPI（Web 框架）用户通过 POST 请求提交图片 URL、卖点等信息
2. 存库PostgreSQL（数据库）创建一条任务记录，状态标记为 pending
3. 排队Redis（队列）把任务 ID 放入一个先进先出的列表
4. 领取Celery（异步任务）Worker 从队列里取任务，同时检查是否有空闲位置（最多同时 3 个）
5. 提交Worker把参数发给 LinkFox API，获得一个 linkfox_task_id
6. 轮询Worker每 5 秒问一次 LinkFox"画好了没？"
7. 记录Worker画好了就把结果图片存回来，失败就记录错误

各状态含义

状态含义
pending任务刚创建，还没进入队列
queued已在 Redis 队列中等待被 Worker 领取
processing已提交给 LinkFox，等待 AI 生成中
completedAI 生成成功，结果已保存
failed失败（超时 / 提交失败 / 生成失败等）
cancelled用户主动取消了任务

🔧 用到的技术

技术角色一句话解释
FastAPIWeb 框架负责接收用户的 HTTP 请求，返回 JSON 响应
PostgreSQL数据库存任务记录、状态、结果
Redis队列 + 缓存任务排队、并发数量控制（最多同时 3 个）
Celery异步任务处理后台默默干活，不阻塞用户请求
Docker部署工具把所有东西打包成一键启动
LinkFox API第三方 AI真正做 AI 生图的平台

❓ 快速排错

403 Forbidden

LinkFox 返回 403，通常有两种原因：

① API Key 没有注入到容器 → 重建容器 docker compose up -d --build

② IP 不在白名单 → 去 LinkFox 后台添加服务器 IP

服务起不来

看日志：docker compose logs api 或 docker compose logs worker

✅ 提示：本项目已部署到阿里云。修改代码后，在本地 push 到 GitHub，然后在服务器执行：
cd /opt/linkfox_services && git pull && docker compose up -d --build
即可更新服务。
