系统概述

📑 目录导航

  • 核心功能
  • 技术选型

LinkFox AI 后端服务是一个完整的任务队列管理系统，用于协调多个商品的AI作图任务。系统支持任务排队、状态监控、结果存储、并发控制、重试机制等功能。

✨ 核心功能

📋
任务管理
创建、查询、取消任务，完整的任务生命周期管理
🔄
智能队列
FIFO队列 + 优先级队列，支持任务优先级设置
🔍
状态轮询
自动轮询LinkFox API，实时更新任务状态
🔄
失败重试
自动重试机制，支持指数退避策略
📊
统计监控
任务统计、队列长度、成功率监控
🖼️
图片存储
结果图片管理，支持本地/OSS/CDN存储
📝
完整日志
任务执行日志，便于问题追踪和调试
🔒
并发控制
限制同时处理的任务数量，防止API超限

🛠️ 推荐技术栈

Python 3.10+ FastAPI Redis PostgreSQL Celery Docker Nginx
💡 建议： 也可以使用 Node.js + BullMQ + MySQL 替代上述 Python 方案

📦 组件说明

  • API Server - 接收HTTP请求，提供任务管理接口
  • Task Queue - 存储待处理任务，管理任务调度
  • Worker Pool - 从队列获取任务，调用LinkFox API
  • Poller - 定期查询任务状态，更新进度
  • Database - 存储任务记录、结果、日志
  • Storage - 图片存储（本地/OSS/CDN）

任务队列

🔄 队列策略

  • FIFO 队列 - 默认先进先出
  • 优先级队列 - 支持设置优先级，高优先级先处理
  • 并发控制 - 限制同时处理任务数（建议 2-5个）
  • 超时控制 - 单任务超时时间（建议 15分钟）

⚡ 轮询策略

  • 初始延迟 - 任务提交后 10s 开始第一次查询
  • 轮询间隔 - 3s-10s，任务多时间隔适当延长
  • 超时时间 - 30分钟未完成标记为失败

🔄 重试策略

重试配置：
  • 最大重试次数：3次
  • 重试延迟：指数退避（10s, 30s, 60s）
  • 重试条件：网络错误、API限流、临时失败

docker-compose.yml

version: '3.8'

services:
  api:
    build: .
    ports:
      - "8000:8000"
    environment:
      - DATABASE_URL=postgresql://user:pass@postgres/linkfox
      - REDIS_URL=redis://redis:6379/0
      - LINKFOX_API_KEY=your_api_key
    depends_on:
      - postgres
      - redis

  worker:
    build: .
    command: celery -A app.workers.task_worker worker --loglevel=info --concurrency=3
    environment:
      - DATABASE_URL=postgresql://user:pass@postgres/linkfox
      - REDIS_URL=redis://redis:6379/0
      - LINKFOX_API_KEY=your_api_key
    depends_on:
      - postgres
      - redis

  postgres:
    image: postgres:15-alpine
    environment:
      - POSTGRES_USER=user
      - POSTGRES_PASSWORD=pass
      - POSTGRES_DB=linkfox
    volumes:
      - postgres_data:/var/lib/postgresql/data

  redis:
    image: redis:7-alpine
    volumes:
      - redis_data:/data

volumes:
  postgres_data:
  redis_data:
